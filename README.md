# Studio Editor Video (APK)
1. Buat repository baru di GitHub, lalu unggah SEMUA isi folder ini (termasuk folder .github dan www).
2. Buka tab Actions, tunggu workflow "Build APK" selesai (sekitar 5-8 menit). Bisa juga dijalankan manual lewat Run workflow.
3. Buka hasil workflow, unduh artifact "studio-editor-video-apk", ekstrak, lalu pasang app-debug.apk di HP.
